= bric3/homebrew-tap
My homebrew formulas repository.

.Install instructions
[source,bash]
----
brew tap bric3/tap
----


* https://github.com/daveallie/grapple[grapple]
+
[source,bash]
----
brew install grapple
----

* https://adoptopenjdk.net/jmc.html[JDK Mission Control snapshot builds]
+
[source,bash]
----
brew install jdk-mission-control-snapshot
----

* https://github.com/jamtur01/grinch[Grinch]
+
[source,bash]
----
brew install --cask grinch
----

* https://www.rarlab.com/[RAR Archiver]
+
[source,bash]
----
brew install --cask bric3/tap/rar
----

NOTE: The official cask was disabled because the upstream binaries fail the macOS Gatekeeper check.
